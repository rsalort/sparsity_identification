# Sparsity Identification and Information Extraction for Quantum States

This repository contains the Python code required to replicate the figures and results presented in the Master's thesis.

## Repository Files

* **`Figures_sparsity_identification.py`**: Script that generates the plots of the document (Figures 5.1 to 5.6).
* **`Statistics_estimation.py`**: Script containing the computation of moments and quantiles.

## Requirements

To run these scripts, you will need Python 3 and the following libraries:

* `numpy`
* `matplotlib`
